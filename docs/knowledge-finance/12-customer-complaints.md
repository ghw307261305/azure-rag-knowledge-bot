# 苦情・相談・紛争対応

## 受付

顧客の発言を遮らず、発生日、対象商品、取引 ID、希望する対応、緊急性を確認します。苦情か問い合わせかを担当者の主観だけで決めず、顧客が不満を表明している場合は苦情として記録します。

## 初動

本 PoC の内部目標では、受付後 1 営業日以内に担当部署と次回連絡予定を案内します。これは法定期限ではなく、架空組織の演示用サービス目標です。

## 調査フロー

1. ケース ID を発行します。
2. 顧客申告とシステム記録を分けて整理します。
3. 通話、操作、取引、承認ログを確認します。
4. 原因、顧客影響、再発防止を評価します。
5. 回答内容を権限者が承認します。
6. 顧客へ結果と利用可能な相談・紛争解決手段を案内します。

## 禁止事項

調査前に責任の有無、返金、補償を確約してはいけません。顧客の申告を虚偽と決めつけず、客観的証跡で確認します。

## FAQ

### Q. SNS に投稿すると言われた場合は優先度を上げますか。

投稿の有無ではなく、金銭被害、個人情報、脆弱性、広範な顧客影響などのリスクで優先度を決定します。
