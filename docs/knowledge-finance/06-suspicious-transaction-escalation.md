# 疑わしい取引の調査とエスカレーション

## 一次調査

一次担当者は、対象取引、顧客属性、過去のアラート、確認済み資料、顧客説明を整理します。「疑わしい人物である」などの主観表現を避け、観察した事実と未確認事項を分けて記録します。

## エスカレーション条件

- 取引目的を合理的に説明できない
- 提出資料に不整合または改ざん疑いがある
- 複数の検知シナリオに継続して該当する
- 制裁対象や高リスク相手先との関連が疑われる
- 顧客への追加確認が調査を妨げる可能性がある

## 対応フロー

1. ケース ID を発行します。
2. AML 担当へ事実、証跡、リスクを引き継ぎます。
3. AML 担当が追加調査と対応方針を決定します。
4. 届出の要否は権限者が判断します。
5. 顧客対応、取引制限、継続監視の方針を記録します。

## 情報管理

調査や届出の有無を、権限のない職員や顧客へ開示してはいけません。ケース情報は Need-to-Know で管理し、閲覧・更新履歴を残します。

## FAQ

### Q. 顧客へ「疑わしい取引として調査中」と説明できますか。

できません。伝達可能な範囲は AML・法務の指示に従い、一般的な確認手続として案内します。
