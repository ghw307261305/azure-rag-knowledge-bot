# 不正送金となりすまし対応

## 主な兆候

- 未登録端末からのログイン直後の高額振込
- パスワード変更と連絡先変更が短時間に連続
- 通常と異なる地域、時間帯、振込先
- ワンタイムパスワードを第三者へ伝えたとの申告
- フィッシングサイトへの入力履歴

## 緊急対応

1. 顧客本人を安全な連絡先で確認します。
2. セッション失効、認証情報の再設定、必要な取引制限を実施します。
3. 未処理振込があれば実行状態を確認します。
4. 不正対策、決済、顧客対応、情報セキュリティへ連携します。
5. 端末、時刻、IP、操作履歴、取引 ID を保全します。

## 顧客案内

暗証番号、パスワード、ワンタイムパスワードを聞き取りません。正規アプリまたは公式サイトから再設定し、同じパスワードを使用している他サービスも変更するよう案内します。

## 補償判断

担当者が即時に補償を約束してはいけません。取引経緯、認証状況、顧客申告、規約、調査結果を基に、所管部署が判断します。

## FAQ

### Q. 不審な振込通知を受け取った最初の対応は何ですか。

通知内のリンクを開かず、公式アプリまたは公式窓口から取引を確認します。不正が疑われる場合は直ちに緊急窓口へ連絡します。
