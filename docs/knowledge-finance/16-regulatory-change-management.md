# 規制・社内規程変更管理

## 目的

法令、監督指針、当局ガイドライン、業界ルール、社内規程の変更を、システム、手順、研修、ナレッジへ漏れなく反映します。

## 変更フロー

1. コンプライアンスが変更情報を受領します。
2. 適用日、対象商品、顧客、業務、システムを特定します。
3. 法務、業務、IT、リスク、監査と影響を評価します。
4. 対応責任者、期限、受入条件を決定します。
5. 規程、画面、帳票、監視、研修、FAQ を更新します。
6. 実施証跡と未対応リスクを管理します。

## RAG ナレッジ更新

Markdown を変更しただけでは完了としません。Knowledge Owner のレビュー、承認、索引再構築、代表質問による回帰確認を行います。旧版は参照停止日と保存先を記録します。

## 緊急変更

施行まで時間がない場合も、口頭連絡だけで終了しません。暫定手順、対象者、終了条件、正式文書化の期限を設定します。

## FAQ

### Q. 当局ページの URL を登録すれば社内手順の更新は不要ですか。

不要にはなりません。外部要件が自社の商品、システム、権限、顧客対応へ与える影響を分析し、実行可能な社内手順へ反映します。
