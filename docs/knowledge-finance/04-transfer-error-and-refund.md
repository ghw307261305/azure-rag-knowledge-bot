# 誤振込・組戻し・返金対応

## 受付条件

依頼人から振込日時、金額、振込先、受付番号、誤りの内容を確認します。暗証番号やワンタイムパスワードは聞き取りません。

## 対応フロー

実行済みの誤振込を組戻しする場合は、次の手順で処理します。

1. 本人確認を行います。
2. 振込ステータスと重複処理の有無を確認します。
3. `RECEIVED` なら取消処理を案内します。
4. `ACCEPTED` または `COMPLETED` なら組戻し案件を登録します。
5. 受取金融機関への連絡、顧客同意、手数料の説明を行います。
6. 結果を顧客へ通知し、対応履歴を保存します。

## 禁止事項

- 返金を確約してはいけません。
- 顧客の了承なく受取人へ個人情報を開示してはいけません。
- 元取引を確認せず、新しい振込で相殺してはいけません。

## 二重引落しの疑い

同一依頼 ID、外部決済 ID、金額、時刻を比較します。表示上の保留と確定取引を区別し、実際に二重計上されている場合のみ訂正処理へ進みます。

## FAQ

### Q. 振込先を間違えました。すぐ戻りますか。

受付状態なら取消できる場合があります。実行後は組戻しとなり、受取側の確認が必要なため、返却時期と成否は確約できません。
