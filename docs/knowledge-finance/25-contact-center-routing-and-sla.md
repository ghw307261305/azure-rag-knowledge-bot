# コンタクトセンター受付区分と対応目標

| 管理項目 | 内容 |
|---|---|
| 文書 ID | SFB-CS-OPS-025 |
| 主管部署 | カスタマーサービス部 |
| 版 | 1.9 |
| 生効日 | 2026-07-01 |
| 機密区分 | 社内 |

## 受付キュー

| キュー | 主な問い合わせ | 受付時間 |
|---|---|---|
| CS-GEN | 商品、住所変更、手数料、一般照会 | 平日 9:00～18:00 |
| CS-DIG | SFB ダイレクト、認証アプリ、ログイン | 平日・土曜 9:00～21:00 |
| CS-FRD | カード紛失、不審ログイン、不正送金 | 24 時間 365 日 |
| CS-COR | 法人振込、承認、ファイルエラー | 平日 8:30～19:00 |
| CS-CMP | 苦情、重大な顧客影響、紛争 | 平日 9:00～17:00 |

受付時間外に緊急性のある不正・紛失申告を受けた場合は、一般照会として翌営業日に回さず `CS-FRD` へ接続します。

## 対応目標

- 一般照会は受付時に回答できない場合、1 営業日以内に担当部署と回答予定日を案内します。
- 取引結果調査は 3 営業日以内の中間回答を目標とします。
- 苦情は 1 営業日以内に受付番号、担当部署、次回連絡予定を案内します。
- 不正送金、カード紛失、不審ログインは待ち時間より利用停止を優先し、その場で緊急処理します。
- 法的判断、補償、返金、審査結果を一次受付担当者が確約してはいけません。

## 受付記録

受付番号、受付日時、本人確認結果、顧客申告、対象取引、実施した緊急措置、引継先、次回連絡日を記録します。暗証番号、パスワード、認証コードは記録しません。

同じ顧客から複数チャネルで連絡があった場合は、受付番号を関連付け、別案件として重複処理しないようにします。

## FAQ

### Q. 深夜にカード紛失の連絡があった場合、翌営業日まで待ちますか。

待ちません。カード紛失と不正送金の `CS-FRD` は 24 時間 365 日受付で、直ちに利用停止を行います。

### Q. 一般照会にその場で回答できない場合はいつ連絡しますか。

1 営業日以内に担当部署と回答予定日を案内します。
