# AML/CFT 取引モニタリング

## 目的

顧客属性と通常の取引パターンを踏まえ、マネー・ローンダリング、テロ資金供与、拡散金融の疑いがある取引をリスクベースで検知します。

## 主な検知観点

- 顧客の職業、事業、資産規模と整合しない取引
- 短期間の多数入出金や資金の即時移動
- 合理的な理由が確認できない複数口座の利用
- 高リスク地域や説明困難な相手先との取引
- 制限回避を疑う分割取引
- 休眠後に突然発生した大口取引

## アラート処理

1. アラートと関連取引を確認します。
2. 顧客情報、過去取引、取引目的、相手先を確認します。
3. 合理的な説明と証跡があるか評価します。
4. 誤検知として終了する場合も判断根拠を記録します。
5. 疑いが残る場合は AML 担当へエスカレーションします。

## 判断原則

単一ルールへの該当だけで不正と断定しません。複数の兆候、顧客リスク、説明、継続性を組み合わせて判断します。モデルスコアは調査の優先順位付けに使用し、最終判断は権限を持つ担当者が行います。

## FAQ

### Q. アラートが出たら直ちに口座を凍結しますか。

一律には凍結しません。緊急性、資金流出リスク、法的根拠、顧客影響を確認し、承認された対応を実施します。
